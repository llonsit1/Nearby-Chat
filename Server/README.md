# Servidor de Nearby Chat

Por ahora para iniciar el servidor se debe seguir los siguientes pasos:

En la carpeta de Server

`npm install` para instalar las dependencias

Finalmente 
`npx tsx server.tsx`

Si todo sale bien deberia aparecer lo siguiente en la terminal/consola

```
Servidor creado
IP:  192.168.1.19
Port:  3000
```

Estos datos se podran usar en Nearby Chat para conectarse al servidor
